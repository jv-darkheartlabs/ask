# Client proposals (`/p/{slug}/`)

This directory is **intentionally empty in git**.

`jv-darkheartlabs/ask` is a **public** repository. Unlisted + `noindex` is not access control — anything committed here is world-readable forever in git history.

Build and host real client pages from a **private** sibling (see [docs/BUILD_GUIDE.md](../docs/BUILD_GUIDE.md)). Only `.gitkeep` and this README are tracked under `p/`.
